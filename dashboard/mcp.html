Connect AI Assistants to this MCP Server

Connect any AI client to automate writing, quality gates, search analytics, and deployments directly from your prompts.

This server is pre-registered in your Antigravity workspace under novamira-clarified-co-za. You can interact with it directly in your assistant prompt:

Please validate the article draft using validate_article_quality and check Google Search Console metrics for top queries over the last 28 days.

Add this to your claude_desktop_config.json file: 

{
  "mcpServers": {
    "clarified": {
      "command": "node",
      "args": ["d:/VS CODE PROJECTS/Clarified.co.za/mcp/server.js"],
      "env": {
        "GITHUB_OWNER": "adolph-mulangatshivalo",
        "GITHUB_REPO": "Clarified.co.za",
        "GITHUB_BRANCH": "main"
      }
    }
  }
}

Everything We Can Do (10 Capabilities)

Interactive catalog of all tools exposed by the Clarified AI Editorial MCP Server.

Protocol: MCP v1.0

validate_article_quality

Editorial Gate

Automated editorial guardian. Checks minimum word count (600+), Flesch readability, focus keyword density (0.5%–2.5%), heading hierarchy, and meta description length.

Word count >= 600 words
Focus keyword density (0.5% - 2.5%)
Meta description (120 - 160 characters)
"Validate the quality of this draft before publishing."

detect_duplicates

Content Integrity

Scans all existing articles for duplicate titles, conflicting URL slugs, or overlapping paragraphs to prevent keyword cannibalization and redundant coverage.

Title similarity score (Dice coefficient)
Slug collision check
Threshold blocking above 60% match
"Check if we already published an article on this topic."

suggest_internal_links

SEO & Linking

Cross-references draft text against all published Clarified articles and generates natural HTML internal anchor links with recommended anchor phrases.

Contextual keyword matching
Ready-to-paste HTML anchor snippets
Category-aware weighting
"Suggest 3 internal links for this article draft."

publish_article

Publishing

The complete publishing pipeline. Runs quality gates, updates database, regenerates sitemap.xml & RSS feed, and commits to GitHub for live Vercel deployment.

Auto-fallback to Draft if standards fail
Auto-updates sitemap.xml & rss.xml
Live Git push to GitHub repository
"Publish this draft to the live Clarified site."

edit_article

Article Mgmt

Updates article content, category, focus keyword, meta description, or status. Re-validates against quality gates and re-deploys updated HTML to GitHub automatically.

Search by ID or Slug
Selective partial field update
Re-generates article HTML on disk
"Update the conclusion of article #14 and save."

get_search_analytics

Search Console

Direct integration with Google Search Console API. Fetches real organic search performance: impressions, clicks, CTR, position, and top queries.

Site: https://clarified.co.za/
Query, Page, Country, Device breakdown
Date ranges: 7, 28, 90 days
"Show me top search queries from Google Search Console."

get_content_opportunities

SEO Opportunities

Discovers high-potential content topics from Google Search Console. Identifies striking distance queries (page 2, positions 8–20) and high-impression queries with low CTR.

Page 2 striking distance keywords
High impressions with low CTR
Actionable editorial recommendations
"Find keyword opportunities where we can rank on page 1."

list_articles

Content Query

Full-text search, category filter, and status pagination across all articles in the repository. Fast and lightweight JSON response.

Filter by category & status
Full text query support
Pagination limit and offset
"List the 5 most recent articles in South Africa category."

get_article

Content Query

Retrieves complete article data, full HTML markup, meta tags, schema markup, and editorial metrics by ID or slug.

Full article HTML body
SEO keywords & structured data
"Fetch full article content for slug 'example-slug'."

delete_article

Safety Guard

Safely removes an article from database, deletes generated HTML pages, and syncs changes directly with the GitHub repository.

Database cleanup
GitHub repository sync
"Delete draft article with ID '12345'."
