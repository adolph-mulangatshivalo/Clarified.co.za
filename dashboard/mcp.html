Everything We Can Do (10 Capabilities)

Interactive catalog of editorial tools exposed by the Clarified AI Editorial MCP Server.

Protocol: MCP v1.0

validate_article_quality

Editorial Gate

Automated editorial guardian. Checks minimum word count (600+), Flesch readability, focus keyword density (0.5%–2.5%), heading hierarchy, and meta description length.

Word count >= 600 words
Focus keyword density (0.5% - 2.5%)
Meta description (120 - 160 characters)
"Validate the quality of this draft before publishing."

detect_duplicates

Content Integrity

Scans all existing articles for duplicate titles, conflicting URL slugs, or overlapping paragraphs to prevent keyword cannibalization and redundant coverage.

Title similarity score (Dice coefficient)
Slug collision check
Threshold blocking above 60% match
"Check if we already published an article on this topic."

suggest_internal_links

SEO & Linking

Cross-references draft text against all published Clarified articles and generates natural HTML internal anchor links with recommended anchor phrases.

Contextual keyword matching
Ready-to-paste HTML anchor snippets
Category-aware weighting
"Suggest 3 internal links for this article draft."

publish_article

Publishing

The complete publishing pipeline. Runs quality gates, updates database, regenerates sitemap.xml & RSS feed, and commits to GitHub for live Vercel deployment.

Auto-fallback to Draft if standards fail
Auto-updates sitemap.xml & rss.xml
Live Git push to GitHub repository
"Publish this draft to the live Clarified site."

edit_article

Article Mgmt

Modifies existing article content, categories, tags, or status, re-renders the static HTML view, and commits changes to production.

Selective parameter updates
Automatic timestamp & date tracking
Preserves slug & SEO rankings
"Update article #3 to published status."

list_articles

Search

Instant search, category filtering, and pagination over the Clarified editorial database for fast indexing and auditing.

Filter by draft vs published
Keyword search across titles & content
Category-specific retrieval
"List all draft articles in Technology category."

get_article

Search

Fetch full article contents by ID or slug including SEO title, meta descriptions, HTML body, and author info.

Complete HTML body payload
Focus keyword & reading time inspection
ID or slug based lookup
"Fetch the full article content for slug 'eskom-loadshedding'."

delete_article

Danger

Safely removes an article from the database, deletes its generated HTML file, and updates sitemaps on GitHub.

Safe deletion from database
HTML file unlinking
Auto-sync with production
"Delete the draft article with ID '1728394012'."

get_search_analytics

Search Console

Queries Google Search Console API for clicks, impressions, CTR, position, and top user queries on Clarified.co.za.

Live clicks & impressions breakdown
Average Google ranking position
Top performing queries & pages
"Show Google Search Console metrics for past 28 days."

get_content_opportunities

SEO Growth

Identifies high-impression queries ranking on Google Page 2 (striking distance) and high-potential article topics.

Page 2 striking-distance discovery
Low CTR opportunity detection
Ready-to-write article pitches
"Find page 2 striking-distance keywords to target next."
